# AI 入口产品边界说明

> 版本：2026-07-15（第 7 阶段任务 64）  
> 前端文案常量：`frontend/src/constants/ai-entry.ts`（须与本文件保持一致）  
> Agent 契约准源：[agent/agent-contract-v1.md](./agent/agent-contract-v1.md)、[agent/agent-security-boundary.md](./agent/agent-security-boundary.md)

## 一、总览

系统提供彼此独立的 AI 相关入口，职责互不重叠：

| 入口 | 路由 | 核心问题 | 输出形态 | 后端 API |
|------|------|----------|----------|----------|
| **智能搜索** | `/search` | 有没有相关文档/段落？ | 检索结果列表 | `POST /api/search/**` |
| **AI 助手** | `/ai` | 这个问题怎么回答？ | 对话式回答 + 可选 RAG 引用 | `POST /api/ai/chat` |
| **AI 写作** | `/ai-writing` | 帮我写/改内容 | 生成或改写后的文稿 | `POST /api/ai/writing/*` |
| **Agent 工作流** | `/agent` | 按已发布流程跑任务 | Run 结果 + 工具轨迹 | `POST/GET /api/agent/**` |
| **Agent 管理** | `/admin/agents` | 如何编排/发布流程？ | 草稿/校验/试跑/发布 | `/api/agent/**`（管理权限） |

```text
用户意图
    │
    ├─ 找资料、定位文档 ──────────► 智能搜索
    ├─ 提问、总结、解释 ──────────► AI 助手
    ├─ 撰写、扩写、优化、续写 ────► AI 写作
    ├─ 运行已发布工作流 ──────────► Agent（/agent）
    └─ 编排/发布工作流（管理员）──► Agent 管理（/admin/agents）
```

## 二、智能搜索

### 职责边界

- **做**：在已发布知识库中检索文档；支持关键词模式与混合智能（语义 + 关键词）模式。
- **不做**：不生成对话式长回答；不撰写新文档；不维护会话历史；不执行多步工具编排。

### 标准文案

| 位置 | 文案 |
|------|------|
| 导航 | 智能搜索 |
| 页面标题 | 智能搜索 |
| 副标题（混合模式） | 在知识库中检索文档，语义 + 关键词混合匹配，适合自然语言问句 |
| 副标题（关键词模式） | 在知识库中检索文档，全文关键词快速定位标题与正文 |
| 一句话定位 | 找文档、找段落——返回检索结果列表，不提供对话式回答 |

### 典型场景

- 「Spring Boot 性能优化」相关文档有哪些？
- 某政策原文在哪份文件里？
- 用自然语言描述需求，找语义相近的内容（混合模式）

## 三、AI 助手

### 职责边界

- **做**：多轮对话问答；可选「知识库增强（RAG）」检索引用来源；保存会话历史。
- **不做**：不返回排序后的文档列表（那是搜索）；不专门生成完整可发布的长文（那是写作）；不执行可配置的多步工作流（那是 Agent）。

### 标准文案

| 位置 | 文案 |
|------|------|
| 导航 | AI 助手 |
| 页面标题 | AI 助手 |
| 副标题 / 侧边栏说明 | 基于知识库的对话问答，可开启知识库增强并引用来源文档 |
| 空态标题 | 您好，我是 AI 助手 |
| 空态引导 | 输入问题即可开始；开启知识库增强后，回答将附带文档引用 |
| 输入框占位 | 输入您的问题，Enter 发送，Shift+Enter 换行 |
| RAG 开关提示 | 开启后 AI 将从知识库检索相关文档辅助回答 |
| 一句话定位 | 提问题、要总结——返回对话式回答与引用，不生成完整文稿 |

### 开关说明

- 受系统设置 `enableAI` 控制；关闭时导航隐藏，访问页展示关闭提示。

---

## 四、AI 写作

### 职责边界

- **做**：按主题与要求生成文稿；支持扩写、优化、续写；可一键跳转创建文档。
- **不做**：不做知识库检索列表；不做开放式闲聊问答；不执行 Agent 工作流。

### 标准文案

| 位置 | 文案 |
|------|------|
| 导航 | AI 写作 |
| 页面标题 | AI 写作 |
| 副标题 | 智能生成、扩写、优化与续写文档内容 |
| 空态标题 | 开始 AI 写作 |
| 空态引导 | 输入主题与写作要求，选择类型与风格，AI 将生成可直接使用的文档内容 |
| 一句话定位 | 写方案、写周报——生成或改写文稿，可一键创建文档 |

### 开关说明

- 受系统设置 `enableAIWriting` 控制；与 AI 助手开关独立。

---

## 五、Agent 工作流（用户侧）

### 职责边界

- **做**：选择**已发布**工作流；填写输入；发起 Run；查看终态答案与逐步工具/LLM 轨迹；提交协作式取消。
- **不做**：不提供 JSON 编辑、草稿保存或发布；不做 React Flow 画布（任务 72）；不做自动多轮记忆；不旁路现有搜索/助手/写作入口。

### 标准文案

| 位置 | 文案 |
|------|------|
| 导航 | Agent |
| 页面标题 | Agent 工作流 |
| 副标题 | 选择已发布的工作流并运行，查看答案与执行轨迹 |
| 空态标题 | 选择一个工作流开始 |
| 空态引导 | 仅可运行管理员已发布的版本；运行结果与工具调用轨迹会显示在本页 |
| 输入占位 | 输入工作流所需问题或关键词 |
| 取消提示 | 取消请求已提交，将在当前节点结束后生效 |
| 关闭态标题 | Agent 功能已关闭 |
| 关闭态说明 | 管理员已关闭 Agent，或当前账号无运行权限 |
| 一句话定位 | 跑已发布流程——返回结构化结果与轨迹，不在此编排 |

### 开关与权限

- 受 `system.enableAgent` 控制（默认生产关闭；任务 71 冒烟通过且 56-Ops 完成前不得开启）。
- 需要 `agent:workflow:view` + `agent:run`；Search ACL 未通过时普通用户不显示入口且访问 403（仅管理员临时可用）。

## 六、Agent 管理（管理员）

### 职责边界

- **做**：用 JSON 文本编辑器创建/更新草稿、校验、试跑、发布不可变版本。
- **不做**：MVP 不做 React Flow；不做面向终端用户的运行入口混入本页。

### 标准文案

| 位置 | 文案 |
|------|------|
| 导航（Admin） | Agent 编排 |
| 页面标题 | Agent 工作流管理 |
| 副标题 | 编排、校验、试跑并发布不可变工作流版本 |
| 一句话定位 | 管理员编排与发布——用户只在 /agent 运行已发布版本 |

### 权限

- `agent:workflow:edit`、`agent:workflow:publish`（默认仅管理员）。

## 七、入口跳转规范

| 来源 | 用户动作 | 应跳转 |
|------|----------|--------|
| 首页 AI 区块 | 点击区块 / 输入问答 | `/ai` |
| 首页快捷芯片 | 智能搜索文档 | `/search` |
| 首页快捷芯片 | 辅助文档编写 / 生成报告 | `/ai-writing` |
| 文档详情 | AI 写作按钮 | `/ai-writing?content=...` |
| 侧栏 / 功能入口 | Agent | `/agent`（需开关与权限） |
| Admin 侧栏 | Agent 编排 | `/admin/agents` |

## 八、与后端模块对应

| 入口 | 主要 BC / 模块 |
|------|----------------|
| 智能搜索 | kb-intelligence-retrieval（Search API） |
| AI 助手 | kb-intelligence-llm（Chat + RAG） |
| AI 写作 | kb-intelligence-llm（Writing Gateway） |
| Agent 运行 / 管理 | **kb-agent**（独立进程；经 Gateway `/api/agent/**`） |

Agent 工具出站经 Gateway 调用 Search / Document，**透传终端用户 JWT**，不使用系统内部 HMAC。
