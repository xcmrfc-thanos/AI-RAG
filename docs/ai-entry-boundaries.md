# AI 三入口产品边界说明

> 版本：2026-07-11（遗留治理任务 40）  
> 前端文案常量：`frontend/src/constants/ai-entry.ts`（须与本文件保持一致）

## 一、总览

系统提供三个独立的 AI 相关入口，职责互不重叠：

| 入口 | 路由 | 核心问题 | 输出形态 | 后端 API |
|------|------|----------|----------|----------|
| **智能搜索** | `/search` | 有没有相关文档/段落？ | 检索结果列表（标题、摘要、高亮、评分） | `POST /search` |
| **AI 助手** | `/ai` | 这个问题怎么回答？ | 对话式回答 + 可选知识库引用 | `POST /ai/chat`（可开 RAG） |
| **AI 写作** | `/ai-writing` | 帮我写/改内容 | 生成或改写后的文稿 | `POST /ai/writing/*` |

```text
用户意图
    │
    ├─ 找资料、定位文档 ──────────► 智能搜索
    ├─ 提问、总结、解释 ──────────► AI 助手
    └─ 撰写、扩写、优化、续写 ────► AI 写作
```

## 二、智能搜索

### 职责边界

- **做**：在已发布知识库中检索文档；支持关键词模式与混合智能（语义 + 关键词）模式。
- **不做**：不生成对话式长回答；不撰写新文档；不维护会话历史。

### 标准文案

| 位置 | 文案 |
|------|------|
| 导航 | 智能搜索 |
| 页面标题 | 智能搜索 |
| 副标题（混合模式） | 在知识库中检索文档，语义 + 关键词混合匹配，适合自然语言问句 |
| 副标题（关键词模式） | 在知识库中检索文档，全文关键词快速定位标题与正文 |
| 一句话定位 | 找文档、找段落——返回检索结果列表，不提供对话式回答 |

### 典型场景

- 「Spring Boot 性能优化」相关文档有哪些？
- 某政策原文在哪份文件里？
- 用自然语言描述需求，找语义相近的内容（混合模式）

## 三、AI 助手

### 职责边界

- **做**：多轮对话问答；可选「知识库增强（RAG）」检索引用来源；保存会话历史。
- **不做**：不返回排序后的文档列表（那是搜索）；不专门生成完整可发布的长文（那是写作）。

### 标准文案

| 位置 | 文案 |
|------|------|
| 导航 | AI 助手 |
| 页面标题 | AI 助手 |
| 副标题 / 侧边栏说明 | 基于知识库的对话问答，可开启知识库增强并引用来源文档 |
| 空态标题 | 您好，我是 AI 助手 |
| 空态引导 | 输入问题即可开始；开启知识库增强后，回答将附带文档引用 |
| 输入框占位 | 输入您的问题，Enter 发送，Shift+Enter 换行 |
| RAG 开关提示 | 开启后 AI 将从知识库检索相关文档辅助回答 |
| 一句话定位 | 提问题、要总结——返回对话式回答与引用，不生成完整文稿 |

### 典型场景

- 「微服务拆分的最佳实践是什么？」
- 「请根据知识库总结 XX 流程的注意事项」
- 需要看到引用来源、可追问的多轮问答

### 开关说明

- 受系统设置 `enableAI` 控制；关闭时导航隐藏，访问页展示关闭提示。

## 四、AI 写作

### 职责边界

- **做**：按主题与要求生成文稿；支持扩写、优化、续写；可一键跳转创建文档。
- **不做**：不做知识库检索列表；不做开放式闲聊问答。

### 标准文案

| 位置 | 文案 |
|------|------|
| 导航 | AI 写作 |
| 页面标题 | AI 写作 |
| 副标题 | 智能生成、扩写、优化与续写文档内容 |
| 空态标题 | 开始 AI 写作 |
| 空态引导 | 输入主题与写作要求，选择类型与风格，AI 将生成可直接使用的文档内容 |
| 一句话定位 | 写方案、写周报——生成或改写文稿，可一键创建文档 |

### 典型场景

- 撰写技术方案、项目周报
- 对已有段落进行润色或扩写
- 从文档详情页带入内容继续写作

### 开关说明

- 受系统设置 `enableAIWriting` 控制；与 AI 助手开关独立。

## 五、入口跳转规范

| 来源 | 用户动作 | 应跳转 |
|------|----------|--------|
| 首页 AI 区块 | 点击区块 / 输入问答 | `/ai` |
| 首页快捷芯片 | 智能搜索文档 | `/search` |
| 首页快捷芯片 | 辅助文档编写 / 生成报告 | `/ai-writing` |
| 文档详情 | AI 写作按钮 | `/ai-writing?content=...` |

## 六、与后端模块对应

| 入口 | 主要 BC / 模块 |
|------|----------------|
| 智能搜索 | kb-intelligence-retrieval（Search API） |
| AI 助手 | kb-intelligence-llm（Chat + RAG） |
| AI 写作 | kb-intelligence-llm（Writing Gateway） |
