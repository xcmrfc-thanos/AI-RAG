# 第 9 阶段：可观测性与交付收口计划

> **状态**：已实施（2026-09-13，与第 7/8 阶段同源推进）
> **定位**：在功能面（第 7/8 阶段）收口后，补齐"看得见、告得到、可恢复"的工程底座，
> 服务于交付演示质量与日常运维效率。

---

## 一、背景

第 7/8 阶段完成后，功能面已收口；但对照交付要求仍有明显缺口：

- **无指标监控**：4 BC 主力服务未引入 Actuator，无 Prometheus 指标，无仪表盘；
- **日志散落**：容器/本地文件各看各的，无聚合检索；
- **SkyWalking 半落地**：dev compose 有 OAP/UI、后端镜像已挂 Agent，但启用依赖手动构建基础镜像，且未纳入冒烟；
- **无告警**：服务挂了没人知道；
- **无 CI**：推送全靠本地手动验证；`verify-all.ps1` 存在中文注释无 BOM 导致的解析错误；
- **备份靠人记**：发版文档仅要求"发版前手动备份"。

## 三、任务拆分（87–93）

### Phase 1：可观测性（任务 87–89，约 2 天）

- **任务 87** ✅ 监控三件套：4 BC + Gateway + Agent + MCP 接入 `spring-boot-starter-actuator` + `micrometer-registry-prometheus`（Agent/MCP 补 micrometer），`application.yml` 暴露 `health,info,prometheus`，指标统一打 `application` 标签；compose 新增 `prometheus`（observability profile，抓 `host.docker.internal` 各服务 8090–8095/18080）。
- **任务 88** ✅ 日志聚合：compose 新增 `loki`（TSDB/文件存储，保留 7 天）+ `alloy`（采集容器 stdout → Loki）；自研服务 dev 形态为宿主机 JVM，日志随容器化交付自然纳入。
- **任务 89** ✅ 仪表盘与告警：Grafana provisioning 数据源（Prometheus/Loki）+「AI-RAG 服务总览」仪表盘（up / JVM 堆 / 5xx 速率 / P99 / Loki 日志面板）+ 告警规则（服务下线 3m、5xx>5req/s 持续 5m）+ 邮件联络点（SMTP 走 `GF_SMTP_*` 环境变量，`deploy/.env` 配置）。

### Phase 2：交付与运维收口（任务 90–91，约 1 天）

- **任务 90** ✅ SkyWalking 收口：全栈形态经 `include: docker-compose.yml` 自然携带 OAP/UI（无需重复定义）；`verify-all.ps1` 增加 SkyWalking UI 探活（可选软检查）。
- **任务 91** ✅ 备份定时化：`deploy/scripts/backup.ps1`（docker exec mysqldump --all-databases | gzip → docker cp 回收，保留 14 天，内附 schtasks 注册示例）。

### Phase 3：CI 与安全复验（任务 92–93，约 0.5 天）

- **任务 92** ✅ 最小 CI：`.github/workflows/ci.yml`（后端编译 + kb-mcp/kb-agent 安全单测；前端 type-check + vitest + build），随 GitHub 镜像 push/PR 触发。
- **任务 93** ✅ 运行时安全复验：新增 `deploy/scripts/verify-security-401.ps1`（无 Token 访问 file/document/agent/mcp/notifications 路由必须 401）并纳入 `verify-all.ps1`；附 SkyWalking UI 软探活。
- **附带修复** ✅ `verify-all.ps1` 中文注释无 BOM 导致 PS 5.1 解析失败（历史存量 bug，`deploy/scripts/*.ps1` 已统一补 UTF-8 BOM）。

## 四、验收口径

| 项 | 口径 |
|----|------|
| 指标 | `docker compose --profile observability up -d` 后 Grafana 能看到 7 个服务 up 状态与 JVM/HTTP 指标 |
| 日志 | Grafana Explore 选择 Loki 可按 `container` 检索容器日志 |
| 告警 | 停掉任一业务服务 3 分钟内产生告警；SMTP 配置后可邮件送达 |
| CI | GitHub Actions push 触发，后端/前端两 job 绿 |
| 备份 | `backup.ps1` 产出 `mysql_*.sql.gz`，过期自动清理 |
| 安全 | `verify-all.ps1` 新增 401 复验步骤全部通过 |
