# Agent 画布上下文操作与连线快捷交互设计

## 目标

在不改变 `schemaVersion=1` 和唯一线性链执行模型的前提下，将 `/admin/agents` 的节点、连线操作从“先选中再去顶部工具栏”优化为就地操作：节点和连线支持右键菜单，连线中点直接选择并插入节点，同时提供清晰的断开入口和键盘快捷键。

## Dify 参考与本系统取舍

2026-07-17 核对 Dify `main` 公开源码：

- `custom-edge.tsx`：连线中点的加号仅在悬停/打开时显示，点击后就地打开 BlockSelector，选中节点后用前后节点信息完成原子插入。
- `node-contextmenu.tsx` 与 `node-actions-menu/context-menu-content.tsx`：节点右键提供运行、复制、创建副本和删除等动作。
- `edge-contextmenu.tsx`：连线右键提供删除，即断开连接。
- `workflow-contextmenu.tsx`：统一承载画布、节点、连线和多选上下文菜单。

本系统保持线性链，因此不复制 Dify 的分支、循环、多选编组和插件节点能力。额外在连线加号弹层底部提供“断开此连接”，提高断开动作的可发现性。

## 交互设计

### 节点右键菜单

- 配置节点：选中节点并保持右侧属性面板可见。
- 复制：写入画布内部剪贴板，不访问系统剪贴板。
- 创建副本：立即在原节点右下方生成新节点并选中。
- 删除节点：沿用“删除中间节点并连接前后”的线性链语义。
- 开始/结束虚拟节点只提供“配置节点”，禁止复制、创建副本和删除。

### 连线加号与右键菜单

- 加号点击后在连线中点打开可搜索节点选择器，不再要求用户去左侧节点库二次选择。
- 选择节点后，原 `A → B` 原子替换为 `A → N → B`；新节点放在 A/B 中点并选中。
- 选择器底部提供危险操作“断开此连接”。
- 连线右键菜单提供“插入节点”和“断开连接”。
- 断开只删除该边，保留两端节点，并显示工作流未连接提示。

### 画布右键与快捷键

- 画布右键：粘贴、自动布局、适应画布。
- `Ctrl/Cmd+C`：复制选中真实节点。
- `Ctrl/Cmd+V`：粘贴到最近鼠标位置；没有鼠标位置时使用画布中心。
- `Ctrl/Cmd+D`：创建副本。
- `Delete/Backspace`：删除选中节点；若选中连线则断开连线。
- `Escape`：关闭上下文菜单或连线节点选择器。
- 输入框、文本域、Select 搜索框或 `contenteditable` 聚焦时不响应画布快捷键。

## 状态、历史与反馈

- 插入、断开、复制后的粘贴、创建副本和删除都通过现有 `commit()` 进入撤销/重做历史。
- 复制本身不修改工作流，不进入历史。
- 右键节点或连线时同步选中目标，菜单操作不依赖此前选择。
- 菜单在点击空白、选择动作、滚动画布、缩放或按 Escape 后关闭。
- 非法或无可用目标时禁用动作并显示明确提示，不静默失败。

## 组件边界

- `workflow-editor-operations.ts`：新增断开边、复制快照、粘贴/创建副本等纯函数。
- `WorkflowContextMenu.tsx`：渲染节点、连线和画布三类菜单，不持有工作流数据。
- `EdgeActionPopover.tsx`：渲染连线中点节点选择器和断开入口。
- `useWorkflowCanvasShortcuts.ts`：集中处理快捷键与输入控件保护。
- `AgentWorkbench.tsx`：只协调节点/边状态、历史提交、菜单目标和组件回调。
- `WorkflowEdge.tsx`：负责边路径、加号触发器和弹层锚点，不直接修改工作流。

## 验收标准

- 右键真实节点可配置、复制、创建副本和删除；虚拟节点不会出现危险动作。
- 点击连线加号可在原地搜索节点并一次完成插入。
- 连线加号弹层和右键菜单都能断开连接。
- 复制粘贴、创建副本、删除和断开支持撤销/重做。
- 快捷键在编辑表单时不误触。
- 线性连接校验、Schema 往返和草稿自动保存保持不变。
- frontend lint、type-check、全量测试、build 和运行页面检查通过。
